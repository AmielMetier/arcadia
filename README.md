# Duo Drift

Jeu de course et de bataille en vue de dessus, jouable en ligne entre potes (jusqu'à 5, en peer-to-peer), directement dans le navigateur.

**Jouer : https://amielmetier.github.io/duo-drift/**

- Modes : Course, Grand Prix, Élimination, Bataille, équipes
- 11 circuits dont 5 grandes villes (Paris, Nice, Milan, New York, Tokyo)
- Clavier ou manette, bots, chat, émotes, garage

by Amiel and Claude
